## 1. Як користувач рухається сайтом

```
Відвідувач
   │
   ├─ обирає місто в шапці (випадаючий список)
   │     → оновлюються курси, відділення, телефон для цього міста
   │
   ├─ клікає пункт у ШАПЦІ (Контакти / Послуги / Переваги / Блог)
   │     → відкривається окрема сторінка розділу
   │
   ├─ клікає іконку в БІЧНІЙ панелі
   │     → на головній: плавний скрол до блоку (#exchange, #contacts…)
   │     → на іншій сторінці: перехід на головну з якорем (/#contacts)
   │     → риска підсвічує активний блок (scrollspy), як на money24
   │
   ├─ на головній дивиться курси / відкриває калькулятор (іконка збоку)
   │     → «Обміняти» / «Створити заявку» → вікно заявки → підтвердження
   │
   ├─ «Дізнатись більше» / «Детальніше» / «Всі статті» у блоці головної
   │     → окрема сторінка розділу (ті самі URL, що в шапці)
   │
   └─ читає блог / сторінку валюти
         → повертається до курсів або заявки
```

**Головне правило навігації — один в один як money24:**

- **шапка** → окремі сторінки (Контакти, Послуги, Переваги, Блог);
- **бічна панель** → якорі секцій на головній (+ Telegram, калькулятор-вікно, соцмережі);
- кнопки «Дізнатись більше» в блоках → ті самі окремі сторінки, що в шапці;
- місто — лише випадаючий список у шапці.

## 2. Дві панелі навігації

Модель: фіксована бічна колонка (`fixed-nav`) + горизонтальна шапка.

### 2.1. Бічна панель

Фіксована зліва на всю висоту. На головній працює **scrollspy**: при скролі активна іконка підсвічується вертикальною рискою.

**Верх панелі**


| Порядок | Пункт       | Дія              | Куди веде                                 |
| ------- | ----------- | ---------------- | ----------------------------------------- |
| 1       | Telegram    | зовнішня вкладка | посилання на Telegram-бот / чат           |
| 2       | Калькулятор | відкрити вікно   | модальне вікно калькулятора (не сторінка) |


**Середина — якірне меню по блоках головної**


| Порядок | Пункт (title)     | Якір на головній | Якщо користувач не на головній |
| ------- | ----------------- | ---------------- | ------------------------------ |
| 3       | Обмін валют       | `/#exchange`     | перехід на `/#exchange`        |
| 4       | Контакти          | `/#contacts`     | перехід на `/#contacts`        |
| 5       | Послуги           | `/#services`     | перехід на `/#services`        |
| 6       | Переваги          | `/#advantages`   | перехід на `/#advantages`      |
| 7       | Новини та відгуки | `/#news`         | перехід на `/#news`            |
| 8       | Інформація        | `/#seo-block`    | перехід на `/#seo-block`       |


**Низ панелі:** YouTube, Instagram, Facebook (зовнішні посилання).

На мобільному — компактний варіант тієї ж логіки.

## 5. Окремі сторінки — що на них і як працює

### 5.1. Курси `/kursy/`

- Повна таблиця курсів з тими самими вкладками (роздріб / опт / крос / крипто).
- Калькулятор обміну.
- Час останнього оновлення курсу.
- Посилання на сторінки окремих валютних пар.
- Кнопка заявки.
- Працює в контексті **обраного міста**.

### 5.2. Сторінка валютної пари `/usd-uah/` (і аналоги)

Приклади пар (стартовий набір як у референсі, склад редагується в адмінці):  
USD, EUR, GBP, PLN, CHF, CNY, TRY, CAD, AUD, SEK, CZK, HUF, AED, ILS + крос-пари (EUR/USD, GBP/USD тощо).

На сторінці:

- актуальний курс купівлі/продажу для цієї пари;
- міні-калькулятор саме для цієї пари;
- зрозумілий текст: що це за валюта, як обміняти, обмеження;
- FAQ по темі пари;
- кнопка заявки з уже підставленою парою;
- внутрішні посилання на інші пари, послуги, блог.

### 5.3. Міста `/mista/` і `/mista/{slug}/`

- Не в шапці й не в бічній панелі: місто обирається **випадаючим списком у шапці**.
- `/mista/` — огляд мережі (за потреби з футера).
- `/mista/{slug}/` — відділення міста, карта, «Обрати це місто», заявка з прив’язкою до відділення.
- Стартовий список міст (як у money24, узгоджується із Замовником): Харків, Київ, Одеса, Івано-Франківськ, Кривий Ріг, Дніпро, Черкаси, Полтава, Кропивницький, Суми, Мукачево.

### 5.3a. Інформація — блок `#seo-block` на головній

- Не окрема сторінка. Іконка «Інформація» в бічній панелі веде на `/#seo-block`.
- Довгий SEO/довідковий текст редагується в адмінці як контент головної.

### 5.4. Переваги `/perevahy/`

- Розгорнутий опис переваг для трьох аудиторій: городяни, гості міста, бізнес.
- Заклик залишити заявку.

### 5.5. Послуги `/posluhy/` і три дочірні


| Сторінка                | Зміст                                     | Дія               |
| ----------------------- | ----------------------------------------- | ----------------- |
| Огляд послуг            | три картки з коротким описом              | перехід у деталі  |
| Перекази по Україні     | як працює, умови, де отримати             | заявка / контакти |
| Міжнародні перекази     | канали, умови, обмеження                  | заявка / контакти |
| Обмін електронних валют | які активи, як проходить обмін на готівку | заявка / контакти |


На сайті **немає** онлайн-оплати й автоматичної виплати — лише пояснення послуги та фіксація звернення.

### 5.6. Контакти `/kontakty/`

- Фільтр / прив’язка до обраного міста.
- Усі відділення: адреса, графік, телефон, посилання на карту.
- Форма зворотного зв’язку (ім’я, телефон, повідомлення, згода на обробку даних).
- Після відправки — повідомлення про успіх; лист/Telegram адміністратору.

### 5.7. Блог `/blog/`

Обов’язковий розділ: окремі URL, Title/Description, schema Article, дати публікації й оновлення, внутрішні посилання, sitemap.

**Список блогу**

- стрічка статей (картка: фото, дата, заголовок);
- фільтр за категоріями;
- пагінація.

**Категорії:**


| Категорія             | Приклад тем                        |
| --------------------- | ---------------------------------- |
| Новини компанії       | відкриття відділень, зміни графіка |
| Послуги               | опт, зношені купюри, перекази      |
| Фінансова грамотність | як вигідно міняти, на що зважати   |
| Формування курсів     | що впливає на курс, огляди ринку   |


**Сторінка статті**

- заголовок, дата публікації / оновлення, автор (за потреби);
- текст зі структурою (вступ → розділи → висновки);
- FAQ у кінці статті (де доречно);
- блок «Читайте також»;
- посилання на калькулятор / заявку / релевантну валютну пару;
- мінімум обсягу та внутрішніх посилань — за `seo_skill` (стаття блогу).

### 5.8. Відгуки `/vidhuky/`

- Стрічка опублікованих відгуків.
- Форма «Залишити відгук» (модерація в адмінці перед показом на сайті).

### 5.9. Політика конфіденційності `/polityka-konfidentsiynosti/`

- Текст політики.
- На цю сторінку веде обов’язковий чекбокс згоди в усіх формах (заявка, зворотний зв’язок, відгук).

## 6. Вікна калькулятора та заявки

### 6.1. Калькулятор

- Відкривається з іконки в **бічній панелі** або з кнопок біля курсів.
- Поля: «Ви віддаєте» (валюта + сума) → «Ви отримуєте» (перерахунок).
- Показує поточний курс і примітку про можливі обмеження суми.
- Кнопка продовження відкриває **вікно заявки** з підставленими сумою й парою.

### 6.2. Заявка на обмін (фіксація курсу)

Відкривається з таблиці курсів, калькулятора, CTA.

**Поля:**


| Поле                                | Обов’язкове | Примітка                              |
| ----------------------------------- | ----------- | ------------------------------------- |
| Ім’я                                | так         |                                       |
| Телефон                             | так         | перевірка формату                     |
| Месенджер (за потреби)              | ні          | Telegram / Viber тощо                 |
| Валютна пара / суми                 | так         | підставляється з калькулятора/таблиці |
| Напрямок: Купити / Продати          | так         |                                       |
| Відділення одержувача               | так         | зі списку **активного міста**         |
| Згода на обробку персональних даних | так         | посилання на політику / правила       |


**Як працює:**

1. Перевірка полів на місці (помилки підсвічуються, відправка блокується).
2. Курс фіксується на обмежений час (орієнтир — **30 хвилин**; точне значення — з Замовником).
3. Заявка зберігається в базі.
4. Миттєве сповіщення адміністратору (Email і/або Telegram).
5. Користувач бачить екран подяки («Заявку прийнято»).
6. Гроші на сайті не списуються і не виплачуються — лише резервування звернення.

## 7. Перемикання міст і курси

### Місто

- Зберігається для сесії відвідувача (і бажано в наступних візитах).
- Впливає на: телефон у шапці, таблицю/калькулятор (якщо курси різняться), список відділень, заявку.
- Доступне **з випадаючого списку в шапці** (і зі сторінок `/mista/…`).

### Курси

- На сайті показуються актуальні купівля/продаж і час оновлення.
- Калькулятор і заявка рахують за курсом, який зараз на екрані.
- Оновлення на вітрині — швидко.
- В адмінці менеджер може змінювати курси вручну (додавати пари, купівлю/продаж, вкладки, резерв/обмеження).
- **Джерело автооновлення курсів узгодимо окремо** — у карті сайту не фіксуємо.
